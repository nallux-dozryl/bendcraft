# Shared world and dropped-entity scene

`entity_scene_render_assets.join(CW.Assets, ItemResources.Assets)` consumes the real resource owners. `Model.Joined{Assets}` has one physical `R.Assets` with the exact world prefix and entity suffix. `Model.Rejected{world,entities,error}` returns both complete originals. `split(Assets)` recovers them for the existing demand loader; rejoin after every successful replacement because the world texture count may change. Immutable catalogs retain their original local slots.

`entity_scene_render.prepare(Context, remote_entity_frame.Frame, Assets, L.Tables)` returns `Assets & Tables & Result<Error,Prepared>`. `draw` has the same owner shape and returns an image. Both failures retain complete physical assets and numerical tables. Preparation calls the actual generic sample/catalog frame selection and world binding paths, then the actual item/XP preparation. It validates every entity quad against its original local texture domain before rebasing into the shared owner. Both passes enter the same `WM.Accumulator`, global quad order and quad/translucency budgets. `draw` calls `M.render` exactly once, so opaque world geometry can occlude dropped items and XP. It does not draw a screen overlay.

`Context{stamp,lighting,render,limits,entity_scan,entity_quads}` uses the exact `remote_entity_snapshot_wire.Stamp` from the atomic frame. Origin, camera, partial tick, registry, dimension, Core tick and revision must all match. The billboard quaternion comes from the real projected camera yaw/pitch using pinned `Camera.setRotation`/JOML `rotationYXZ` arithmetic. Item positions use the existing renderer's actual F64 `position_old` interpolation.

`Lighting.Missing{reason}` explicitly refuses. `Lighting.Stable{stamp,cells,entities}` is the consumer seam for an authoritative settled publication: cells are `Map<Maybe<WorldLight{state,block,sky,rgb}>>` keyed by `GS.point_key`, and entities are existing `D.Light{id,block,sky,item_rgb,orb_rgb}` rows. Block and sky levels must be 0..15, RGB must have opaque alpha, each visible world sample's state must match. Invisible catalog entries need no light sample. Missing cells or missing visible-entity light rows refuse through the real producer. Stable is supplied authority, not a proof of a caller's provenance. Its RGB is the evaluated lightmap for the same render environment; levels alone do not determine RGB.

The current atomic `remote_entity_frame.Frame` has no light field. The live owner must sample real settled block and sky fields under the same Core clock and publish evaluated lightmap colors, then build Stable with that frame's exact stamp. No constant sky=15, white default, inferred unloaded air or fake entity View is supplied here. The sky owner is adding a field-only state and owner-preserving sample batch; Session and lightmap publication remain integration-owner work.
