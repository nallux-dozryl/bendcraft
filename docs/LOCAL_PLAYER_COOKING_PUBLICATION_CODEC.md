The standalone publication recovery codec carries the complete incarnation
Patricia tree and publication journal under the NBT root
`bendex:cooking-publication`, format 1. Tree nodes retain their exact split bit and
two branches; leaves retain canonical `dimension/x/y/z` keys and native 48-bit
natural counters. Removed-owner counters remain part of that tree.

The focused consumer is
`python3 -B tools/test_local_player_cooking_publication_codec.py --native`.
It checks the complete original Bend source, performs one native build attempt,
then compares production encoding with independently constructed ordered NBT.
It reuses the bounded process and cleanup helpers from the entity codec test.
Completed attempts remain under
`build/local-player-cooking-publication-codec/checks/`; input drift is refused
without an automatic rebuild.

The golden tree has four canonical keys and split positions 358, 823 and 824. An
additional physical fixture covers the prefix-termination split at 825. Acceptance
requires byte-exact topology preservation. The journal fixture includes the
maximum native Nat 281474976710655, an older dirty chunk revision, raw signed
coordinate words and an exact latest receipt. All six binding families and both
cached LIT states are covered. The captured binding's block string carries NUL,
a supplementary character and two isolated UTF-16 surrogate words in its
IntArray representation. That structural codec test does not authenticate the
block string against a loaded catalog.

Refusal fixtures cover exact member names/order/types, missing/duplicate/unknown
members, empty-list element tags, malformed/truncated/trailing physical NBT,
byte/depth/element budgets, noncanonical or overflowing natural numbers,
noncanonical position keys, invalid trie positions/branches/partitions and
duplicate keys. Journal refusals cover the latest receipt sequence, position and
chunk relationship, duplicate dirty chunk keys, bounded dirty revisions,
known dimensions, valid section coordinates and cached LIT partnership. The
receipt incarnation must not exceed the saved counter for its exact key; an
older historical receipt is accepted and a missing key means counter 0.

The complete golden image needs exactly 2161 bytes, six container levels and a
maximum array cardinality of 53. The fixture tests those combined bounds and
independently refuses one below each bound for both encode and decode.

The journal's declared structural invariant permits unique dirty chunks with
revisions between 1 and the latest sequence. This test does not claim that every
accepted structural image can be generated by a complete `marked`/save history.
It also does not establish catalog authentication, live effect publication,
atomic file interruption recovery or actor cold restoration. Those belong to
their actual joined consumers.

accepted and reencoded byte exactly, and 421 refused. Complete original CLI

with no retry. Native guards and the physical corpus took 0.798 and 1.132 seconds.
All owned process groups exited. The independently encoded 2161-byte golden
image matched SHA-256
`f036ab47cd9b943f9671d6070399acba5f1798f7d429e4e434a802b08a43e453`.

Attempt 001 stopped in 0.688 seconds at an oversized `4294967296n` test literal;
the parser permits Nat literals only through `4294967295n`. The fixture now
constructs the same larger value with exact Nat arithmetic. That retained
[source failure](../evidence/local-player-cooking-publication-codec-001-failure.json)
preceded native emission. No production codec change was made by this test lane.
