# Checked local-travel fall-reset join

`TH.travel_with_reset_checked(state,tables,ResetRequest)` supplies an actual
required fall-reset ray through `FR.clip_checked`. `MH.State` remains the only
movement/history owner. The additive types and definitions preserve all original
TH units byte-for-byte after the three new imports are removed.

The sole Body is prepared and moved once. LM forms the movement candidate; TH
derives the ray from original feet and the resolved displacement with the
vanilla length-eight cap. A required ray runs before H history completion and
travel finish. Nonrequired rays perform no supplier reads. No caller-supplied
Body, endpoint, fabricated MISS or extra movement is accepted.

This ordering is admitted only for the fixed neutral, read-only services with
no observable callback. Reset hits, damage, dimension changes, data-pack tags
and nonneutral block callbacks remain unsupported. Every admitted failure
restores the exact pre-travel Body/view/cache/support/minor/history anchor and
returns the Core and sine Tables owner. Structural owned tails are retained on
refusal rather than dropped.

`tests/local_travel_reset.bend` exports `arguments(table <> commands)` for the
shared consumer's `travel-reset-cases` mode. It uses ten actual whole-travel
calls, including five required MISS rays and five calls requiring no ray. Two
additional actual MH fixtures exercise only endpoint/supplier phases and are
not promoted to whole-travel observations. Twenty-four policy processes probe
checked refusal, rollback and reuse of returned owners. The existing native
supplier fixture binds ordered block/fluid reads to the actual pinned 26.3 ray
observations.

`tools/test_local_travel_reset.py` provides `suite(executor)`. The parent
supervisor owns admission, execution limits, complete closure/binary pins and
process cleanup. This helper formats fixture words and compares actual
observations; it does not build an executable, extract Java, calculate gameplay
expectations or launch a native process itself. Existing independent serializers
and comparison helpers remain unchanged.

The retained ordinary checks pass for source003 and harness003 under
`build/local-travel-reset/`. No repeat of those unchanged checks is needed.
Native comparison belongs to the new shared savedLocalPlayer consumer artifact
after independent FR native admission. An ordinary pass is not native parity
or an independent-kernel proof.

The staged facade policy uses whole-cell `[-64,64]^3`, 128 read-work units,
`FR.DefaultClientOverworldFourState` and an empty policy tail. The bounds never
grow around a Body and missing sections are never treated as air. The facade's
resume call is enabled after independent supplier native admission and root's
exact activation grant. Native verification of the shared saved consumer remains
pending.
