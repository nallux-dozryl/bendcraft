## Affine API and admission

`SlabType` is `TopSlab | BottomSlab | DoubleSlab`. `Entry{state_id,slab_type,waterlogged}` is immutable Data. `Sample{state_id,slab_type,waterlogged,collision:Geometry.Collider}` returns the exact queried state ID, actual properties and one BoxCollider. `Catalog{entries:Array<Entry>,count,state_count,identity}` owns one 1,024-slot array; only the 606 strictly ordered entries are admitted. Binary search performs at most ten array reads, with eleven terminating fuel steps including an absent-state boundary.

- `Catalog.parse(identity,state_count,text)` and `Catalog.decode(identity,state_count,bytes)` admit only the exact pinned table. UTF-8, byte validity, count, version/layout and SHA256 checks precede trusted queries. The byte limit is 16,384; the table occupies 8,519 bytes.
- `Catalog.bind(registry,text)` and `Catalog.load(registry,path)` obtain the actual `Registry.identity` and state count and return that registry owner beside the Result. A foreign registry is rejected rather than remapped. File reads probe one trailing byte to enforce the limit and close their handles on all branches.
- `Catalog.query(catalog,identity,state_id)` returns the catalog owner beside Result<Error,Sample>. It checks conditional caller identity and registered-state bounds before array access, then validates catalog public metadata and actual array capacity. A valid registered non-slab returns `UnsupportedState`; a state ID at or above 35,723 returns `InvalidState`. Neither error infers air or a full cube.
- `Catalog.replace(catalog,text)` fully admits the replacement before swapping owners. Every admission failure returns the previous owner. A valid replacement can recover deliberately malformed public catalog metadata.

The canonical registry identity is `4f75fa335a12e34cf74be71ff6a0ee530b13233212423f5463bb26a2fe4f3cfc`. The derived table SHA256 is `e36cb6c6bd59dea0b4bd6300eb96ff61bf689ef006029bc9b954b042cc630856`. Parsing checks exact canonical bytes; semantically similar reordered rows, changed newline forms or correctly spelled but altered TYPE values are integrity failures.

The identity argument to query is conditional caller authority, not authentication of a world. Copyable strings cannot establish the identity of arbitrary external context. Bind/load verify an actual Registry owner; a future Core/world adapter must verify its own Registry and dimension/cell policy. Public raw constructors and lower-level schema/search helpers are outside integrity admission. Query detects tested malformed metadata/capacity and out-of-registry visited entries, but it does not rehash or authenticate arbitrary caller-constructed arrays. That distinction is part of the API contract.
